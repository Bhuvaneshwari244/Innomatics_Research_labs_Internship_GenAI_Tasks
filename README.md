## 📂 Phase 2: Generative AI (Prompt Engineering & LangChain)

### 3. Mastering LangChain Prompt Templates
**Folder/File:** `Task1_GenAI_Prompt_Templates.ipynb`

This assignment marked the transition from traditional NLP to Generative AI. The objective was to shift from hardcoded, static prompts to dynamic, modular, and reusable prompt systems using the LangChain framework.

* **Frameworks Used:** `langchain_core`
* **Key Implementations:**
    * **Dynamic Templating:** Replaced f-strings with `PromptTemplate` for multi-variable inputs.
    * **Chat Roles:** Implemented `ChatPromptTemplate` to structure interactions using specific System and User roles.
    * **Validation Layer:** Engineered a `validate_inputs` function to handle invalid user configurations by falling back to safe default values.
    * **Prompt Generator App:** Built a unified pipeline: *Input Validation → Style Selection → Prompt Formatting*.

**Folder/File:** `Task3_Resume_Screener.ipynb`

* **Frameworks:** `langchain`, `langsmith`, `huggingface`
